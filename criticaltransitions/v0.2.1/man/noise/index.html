    Noise processes

    CriticalTransitions.gauss — Method
    gauss(sys::StochSystem)

    Returns a Wiener process with dimension length(sys.u) and covariance matrix sys.Σ.

    This function is based on the CorrelatedWienerProcess of DiffEqNoiseProcess.jl, a component of DifferentialEquations.jl. The initial condition of the process is set to the zero vector at t=0.
